# Ozon Parser JSON

Легковесное расширение для Chrome (Manifest V3), которое собирает данные о товарах со страниц листинга Ozon и упаковывает их в чистый JSON.

## Возможности

* Парсит поисковую выдачу и каталоги: извлекает SKU, названия, текущие и старые цены, скидки и прямые ссылки на товары.
* Защита от битых названий: если верстка меняется, заголовок автоматически восстанавливается из URL (slug).
* Два режима экспорта: скачивание готового `.json` файла либо мгновенное копирование в буфер обмена.
* Вывод включает метаданные: целевой URL, время сбора и общее количество позиций.

## Установка

1. Клонируйте репозиторий или скачайте архив с кодом.
2. Откройте в Chrome страницу `chrome://extensions/`.
3. Включите **Режим разработчика** в правом верхнем углу.
4. Нажмите **Загрузить распакованное расширение** и выберите папку проекта.

## Использование

1. Откройте нужную страницу с товарами на Ozon.
2. Кликните по иконке расширения на панели браузера.
3. Выберите нужное действие: скачать файл или скопировать JSON.
